# Angular Portfolio (earlier version)

My first portfolio website, built as an Angular 17 single-page app with server-side rendering.

**Pages:** Home · About · Services · Resume · Portfolio · Contact, plus a shared sidebar component.
**Projects shown:** Skinalyze (final year AI skincare app), real estate site, quiz app, chatbot, to-do list and email subscription page.

## Run it

```bash
npm install
npm start          # http://localhost:4200
npm run build      # production build in dist/
```

Built with Angular 17, TypeScript and Font Awesome.
