RC-01MediumUI · Real finding

Netlify pill covers the WhatsApp chat button

Environment

Chrome on Windows, desktop width 1900px · royalchilghoza.pk

Steps to reproduce

  1. Open the home page on a desktop browser.
  2. Scroll to any section.
  3. Look at the bottom-right corner.

Expected

The WhatsApp button is fully visible and clickable.

Actual

A dark pill overlaps the button and hides its icon.

Evidence

Suggested fix

Give the chat button bottom: 88px on desktop, or hide the pill in site settings.

AC-07CriticalAccess control · Demo

Employee can approve their own expense claim by editing the URL

Environment

Test server · Employee role · Chrome

Steps to reproduce

  1. Log in as an Employee and submit a claim.
  2. Open the claim. Note its ID in the URL, e.g. /claims/1042.
  3. Change the URL to /claims/1042/approve and press Enter.

Expected

Access denied (403). The claim stays “Pending”.

Actual

The approval page loads and the claim changes to “Approved”.

Why it matters

The approve button is hidden in the UI, but the server does not check the role. Any employee could approve payments.

Suggested fix

Check the user's role on the server for every approve request, then retest with all roles.

AC-07 shows my reporting format. The scenario is invented for this portfolio and does not describe any employer's or client's system.
